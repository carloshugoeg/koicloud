# CLAUDE.md

Este repositorio usa **`AGENTS.md` (raíz) como fuente única** de reglas para agentes.
Léelo completo antes de tocar cualquier archivo y cúmplelo: identidad y ticket (§1),
contratos congelados (§2), propiedad de rutas (§3), autoría de commits (§7),
prohibiciones (§8) y protocolo de PR (§9).

No añadas `Co-authored-by: Claude`, «Generated with Claude Code» ni ningún trailer de
herramienta a los commits. Cada commit va firmado con la cuenta de GitHub real de la persona
que hizo el trabajo (`AGENTS.md` §7).
